# EaglerCraft Launcher 3.1.0

## 3.1.0 — Complete UI redesign

- Replaced the forest-green look with a graphite desktop-launcher theme and violet accents.
- Redesigned sidebar, player profile, game dashboard, version selector, launch bar, settings, cards and utility panels.
- Improved responsive layouts, focus visibility and theme switching.

## 3.0.0 — Launcher refurbishment

## Launcher refurbishment

- Refreshed the shared interface with a forest-green visual system and responsive mobile styling.
- Reworked the home dashboard and added consistent access to the Feature Hub.
- Added the Launcher Tools command center and quick navigation.
- Added local profile save/switch, server bookmarks, recent launch history, notes, diagnostics, keyboard shortcuts and JSON workspace backup/restore.
- Added favorite versions and launcher-wide preference controls.
- Updated the visible launcher version and release log.
- Replaced the placeholder README with setup, compatibility and browser-data documentation.

## Important scope notes

- The Feature Hub's 210 controls are local preference records, not 210 separate gameplay features.
- The launcher does not generate new game versions or bypass browser security restrictions.
- Existing client files and their respective terms remain applicable.
- The repository's old `GX-Launcher 2.0.zip` is a legacy archive, not the 3.0.0 package.
